# output/ — the evidence

Generated, and **committed**. Most projects ignore their build output; this one tracks
it, because the documents and reports here are the evidence for the manuscript's
claims. A reader should be able to clone the repository and inspect the artefacts
rather than take the numbers on trust.

Everything here is reproducible from source: `./run.sh` rebuilds all of it.

## What is tracked

| Directory | Contents |
| --- | --- |
| `documents/` | every built artefact — the example, the dossier, the living manuscript, both project round trips, the real-repository carry in all four names, and the rendered `manuscript.pdf` |
| `figures/` | the manuscript plates, generated by `scripts/build_figures.py` |
| `reports/` | the JSON the manuscript's numbers are read from: `roundtrip`, `project_roundtrip`, `template_roundtrip`, `dossier`, `living_manuscript` |
| `manuscript/` | the token-substituted sections the PDF is compiled from |

## What is not

`data/` and `roundtrip/` are ignored (see [`../.gitignore`](../.gitignore)) —
`data/manuscript_variables.json` is regenerated on every render, and `roundtrip/`
holds extracted trees that exist only to be diffed against their originals during the
run.

## The four names

`documents/` carries each container under two names, byte for byte identical:

| Surface name | Intelligence name | |
| --- | --- | --- |
| `.docx` | `.docxplus` | OOXML |
| `.odt` | `.odtplus` | ODF |

An extension is a claim about content. The surface name says "an ordinary document";
the intelligence name asserts a signed intelligence layer. `docxplus validate` is what
turns the assertion into a verdict, and either name validates, because they are the
same bytes.

## Reading the reports

`reports/*.json` is consumed by `src/manuscript_vars.py`, which is how a figure in the
paper stays tied to a measurement. `template_roundtrip.json` is the one to read first:
it records 126 files across 15 directories carried through both profiles and diffed
back, content and executable bit, with an empty `failures` list as the only acceptable
result.
